About the Shift Playground

        

            
Welcome to the official playground environment for the Shift Language.

            
The Shift Project is currently hosted on Github.
Please visit it here to learn more.

            
This tool allows you to write, edit, and execute custom scripts directly in your browser using the Virtual File System.
