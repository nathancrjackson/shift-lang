The Shift Project's Test Track

        

            
Welcome to the official environment for test driving the Shift language.

            
The Shift Project is currently hosted on Github.
Please visit it here to learn more.

            
This interactive tool lets you write, tweak, and run Shift scripts right in your browser, powered by a virtual file system designed for experimentation.

            
The Shift project is managed by Nathan Jackson and is sponsored by DTC Group

            
Please note: The Shift Project is still in early development so the language, its runtime and this test environment may be subject to backwards compatibility breaking changes.
